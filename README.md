# Mega Telegram Bot

Большой пример Telegram-бота на Python (long polling, без сторонних библиотек).

## Запуск

```bash
export TELEGRAM_BOT_TOKEN="<ваш токен>"
python mega_telegram_bot.py
```

## Что внутри

- Профили пользователей, XP/уровни и монеты.
- TODO и заметки.
- Ежедневные награды и работа с кулдауном.
- Напоминания.
- Цитаты.
- Сотни команд `tip_*` и `challenge_*`.
